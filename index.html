Format 2: Structured (with metadata)

URL | Title | Tags | Description

Tips:

  • Use | to separate fields (URL | Title | Tags | Description)
  • Tags should be comma-separated
  • Leave Title empty to auto-generate from URL
  • Lines starting with # are treated as comments
  • Batch tags below will be added to ALL imported links

Setup Guide

How to create a GitHub Personal Access Token
  1. Go to GitHub Settings → Developer settings → Personal access tokens
  2. Click "Generate new token" → "Generate new token (classic)"
  3. Give it a descriptive name (e.g., "LinkSmith Sync")
  4. Select expiration: "No expiration" or choose your preference
  5. Select scopes: Check gist (Full control of gists)
  6. Click "Generate token" at the bottom
  7. Copy the token immediately (you won't be able to see it again)
  8. Paste it in the "GitHub Personal Access Token" field above

Security: Your token is stored locally in your browser and never sent to any third party.

How does Gist sync work?

GitHub Gist provides free cloud storage for your LinkSmith data:

  • FREE: No cost, 5000 API requests/hour
  • Private: Your Gist can be private (only you can see it)
  • Cross-device: Access your links from any device with a browser
  • Automatic merging: Intelligently merges data from multiple devices
  • Size limit: 10MB per Gist (enough for ~10,000 links)

Data flow: Your browser ↔ GitHub Gist ↔ Other devices
