Import Links

Paste URLs to import them into your knowledge pool. Supports two formats:

📋 Import Formats (click to expand)

Format 1: Simple (just URLs)

https://www.youtube.com/watch?v=example
https://medium.com/article-example
https://github.com/user/repo

Format 2: Structured (with metadata)

URL | Title | Tags | Description

https://www.youtube.com/watch?v=example | JavaScript Tutorial | programming,js,tutorial | Great intro video
https://medium.com/article | | programming,article
https://github.com/user/repo | My Awesome Project | github,opensource

Tips:

  • Use | to separate fields (URL | Title | Tags | Description)
  • Tags should be comma-separated
  • Leave Title empty to auto-generate from URL
  • Lines starting with # are treated as comments
  • Batch tags below will be added to ALL imported links
