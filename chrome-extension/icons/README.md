# Extension Icons

Please add the following icon files to this directory:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Quick Icon Generation

You can create simple icons using:

1. **Online tools**:
   - https://www.favicon-generator.org/
   - https://realfavicongenerator.net/

2. **Design software**:
   - Figma, Canva, Photoshop

3. **AI generation**:
   - Ask an AI to generate a link/chain icon with purple gradient

## Recommended Design

- Theme: Purple gradient (matching LinkSmith brand: #667eea to #764ba2)
- Symbol: Chain link 🔗 or bookmark icon
- Style: Modern, minimal, flat design

## Temporary Solution

For testing, you can use any square PNG images with the correct dimensions. The extension will work without icons, but Chrome will show a default placeholder.
