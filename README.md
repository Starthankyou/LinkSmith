# LinkSmith
A private, controllable, searchable, and randomly retrievable personal information pool.

A personal reading hub for managing thousands of saved links, videos, and articles without relying on platform algorithms.  
Features include bulk link import, tags, search, unread/read status, and a random content picker to help you rediscover old saved items.  
Built as a lightweight web app and deployed on GitHub Pages.

一個「個人資訊池」的輕量網頁工具，用來整理上千筆收藏的網址、影片與文章。  
不依賴任何平台演算法，而是讓使用者自行掌握學習內容。

核心功能包含：  
- 大量匯入連結  
- 自動擷取標題與網域  
- 標籤與搜尋  
- 未讀／已讀標記  
- 隨機抽選下一個內容  
- 可部署於 GitHub Pages

這是為了讓資訊不再只是收藏，而能真正被消化與吸收的個人化閱讀工具。
